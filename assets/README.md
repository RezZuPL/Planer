# Grafiki planera

Wszystkie użyte grafiki SVG znajdują się w tym folderze:

- `planer-mark.svg` — znak marki wyświetlany przy nazwie Planer i na ekranie hasła
- `ui-icons.svg` — symbole nawigacji, kalendarza, zadań, notatek i ustawień

Możesz edytować te pliki SVG albo podmienić je na własne pliki o tych samych nazwach. Jeśli dodasz grafikę pod inną nazwą, zmień też ścieżkę `assets/nazwa-pliku.svg` w `index.html`.
